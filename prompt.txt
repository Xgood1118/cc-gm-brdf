在现有 brdf 骨架上，把它做成一个物理上站得住的 BRDF 预计算器。保留 clamp01、ndf_ggx、fresnel、
brdf_value、build_lut、energy_check、save_lut_png 的现有名字与签名，只用 Python 标准库，不得引入
第三方依赖，不得改动 data/samples.json。

## 需要完成

1. **分布函数**
   - 法线分布要满足归一化，在半球上积分结果为 1，误差不超过 2%。
   - 粗糙度从 0.05 到 1.0 之间，高光峰值宽度要随之变化。

2. **菲涅尔**
   - 反射率随入射角变化，掠射角接近 1，正视时接近基值。
   - 基值可由参数给出。

3. **查找表**
   - 表是粗糙度与视线夹角两个维度的真实二维表，不同粗糙度行不能是同一曲线的缩放。
   - 表内所有值都在 0 到 1。

4. **能量守恒**
   - 漫反射加镜面反射的半球积分要接近 1，误差上限写进 README。
   - `energy_check` 要给出这个比较结果，不能只返回平均值。

5. **采样点校验**
   - `samples.json` 里每个点的计算结果要落在它的期望区间内，越界的点要在报告里点名。

6. **测试**
   - 覆盖：分布归一化、菲涅尔单调、表二维性、能量守恒、采样点区间。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m brdf.cli --roughness-steps 16 --view-steps 16 --out lut.json`，把能量积分结果、
5 个采样点的计算值与期望区间贴进 README。
